# Tolkien - colour - transparent

The `pixmaps` folder contains generated 512 × 512 foreground-only RGBA background
tiles for MMapper, using the approved colour overlays. Field is completely
transparent, ready for a separate large parchment layer underneath the map.

Choose this folder or its `pixmaps` subfolder as the separate custom tile pack in
Preferences → Background Map. There are 27 PNGs, including all 16 road variants.
The parchment-underlay rendering feature is separate from this artwork.

Masters are in `working folder/Assets-colour`. GitHub Actions rebuilds this pack
whenever approved sources or the build mapping change. See the repository README
for details.
