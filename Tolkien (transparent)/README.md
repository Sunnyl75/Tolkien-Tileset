# Tolkien (transparent)

The `pixmaps` folder contains generated 512 × 512 foreground-only RGBA background
tiles for MMapper. Field is completely transparent. This pack is intended for use
with a separate parchment underlay; that rendering feature is independent of
these PNGs.

These files are generated from approved masters by `scripts/build_tilesets.py`.
See the repository README for updates and rebuilding. Do not edit these exports
directly; full-resolution masters are kept in `working folder/Assets`.
