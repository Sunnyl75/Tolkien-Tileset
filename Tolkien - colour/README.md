# Tolkien - colour

The `pixmaps` folder contains generated 512 × 512 opaque background tiles for
MMapper. Approved colour overlays are composited over the original Field
parchment at master resolution, then reduced. Field is the parchment alone.

Choose this folder or its `pixmaps` subfolder as the separate custom tile pack in
Preferences → Background Map. There are 27 PNGs, including all 16 road variants.

Masters are in `working folder/Assets-colour`; Field is shared from
`working folder/Assets`. GitHub Actions rebuilds this pack whenever approved
sources or the build mapping change. See the repository README for details.
